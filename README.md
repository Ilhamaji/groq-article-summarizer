# Modul Peringkasan Teks Llama-3.3-70B

Modul ini digunakan untuk melakukan peringkasan dokumen PDF
menggunakan model Llama-3.3-70B melalui Groq API.

## Teknologi

- Python
- Google Colab
- Llama-3.3-70B
- Groq API
- PyMuPDF
- BeautifulSoup
- Regular Expression

## Instalasi

```bash
pip install -r requirements.txt
